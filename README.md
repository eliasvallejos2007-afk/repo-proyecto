## Descripción del proyecto

Este proyecto consiste en el análisis de un conjunto de datos de ventas de una pequeña empresa utilizando Python y la biblioteca Pandas.

El objetivo es procesar información de ventas para obtener indicadores básicos de desempeño comercial.

---

## Estructura del proyecto

- `datos/` → Contiene el archivo CSV con los datos de ventas.
- `scripts/` → Contiene los programas en Python.
- `resultados/` → (opcional) carpeta para salidas o gráficos.

---

## Funcionalidades implementadas

El script principal realiza las siguientes tareas:

- Carga de datos desde un archivo CSV.
- Cálculo de ventas totales.
- Identificación del producto más vendido.
- Cálculo de ventas por mes.
- Visualización de resultados por consola.

---

## Tecnologías utilizadas

- Python
- Pandas
